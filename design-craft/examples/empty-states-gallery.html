Empty States Gallery

Editable recreations of the visual lessons in references/component-details.md → Empty states. Every card shows the same message so only the visual changes. Pick one style for the whole product; the later sections reuse a single style (Preview) on purpose. Buttons and links are static examples, not controls.

1. Seven styles, one message

Same title, line and action in each card. Only the picture above the words changes. None is wrong; the failure is a product that uses all seven. Shared anatomy: visual, 20px gap, 14px/500 title, one 13px muted line, one 28px secondary button.

2. One style across causes

Pick a style once and reuse it. Here Preview carries every cause; only the ghost row's glyph, the title and the action change. Done has no button; no access names a person instead of showing a disabled button.

3. One component, three sizes

Page: visual, title, line, button. Card: no visual, a text link. Inline: one line in the row. Page and Card are the same markup in a container-query wrapper (.empty.sized): under 240px wide it drops the visual and swaps the button for a link.

4. Charts: missing is not zero

Keep the axes. With nothing measured, draw no line and put a small label in the plot area. A line along zero claims a measured zero.

5. Before / after: same component, same frame

The table frame and component stay put. The after version changes the copy, adds the product's one visual style and cuts two equal buttons to one.
