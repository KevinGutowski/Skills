# Sources

**Sources:**
- *Laura Kalbag, Accessibility for Everyone (A Book Apart, 2017)* — the spine: practice, priority order, testing, org layer
- *Michael J. Metts & Andy Welfle, Writing Is Designing, ch. 5 "Inclusivity and Accessibility" (Rosenfeld, 2020)* — the writing-accessibly layer
- *Adham Dannaway, Practical UI (2nd ed., 2024)* and *Wathan & Schoger, Refactoring UI* — the contrast-metrics layer (§5b)
- *W3C WAI, WCAG 2.2 Understanding documents* — current Focus Not Obscured, Focus Appearance, and Target Size distinctions: https://www.w3.org/WAI/WCAG22/Understanding/
- *W3C WAI, ARIA Authoring Practices Guide, Developing a Keyboard Interface* — native-vs-custom keyboard behavior and composite-widget focus conventions: https://www.w3.org/WAI/ARIA/apg/practices/keyboard-interface/
