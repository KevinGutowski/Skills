# Client Work

**Sources/gaps:** [references/sources.md](references/sources.md) maps the client-engagement and pricing corpus; [references/coverage-gaps.md](references/coverage-gaps.md) tracks legal/contract and exemplar candidates.

Start with the one reference below that matches the task; each carries the full distillation for its area. Read the second only when the task crosses the seam (for example, a pricing dispute inside a running engagement) — each reference says where it hands off to the other.

**Second hop:** deeper worked examples, scripts, and sources live in a same-named subdirectory next to each reference (`references/<name>/…`). The bullets name every member; open a member through its parent reference, which says when each applies.

- **Engagement mechanics** — qualifying clients before scoping, kickoff, sign-off gates, the feedback system (honesty preamble, like-ban, one voice), health signals and anti-patterns, mistakes and come-to-Jesus meetings, firing or being fired, testing with clients: [references/client-engagements.md](references/client-engagements.md). Second-hop members under `client-engagements/`: feedback-system (presentation and feedback scripts), health-and-failure (health signals, mistakes, firing, termination money), sources.
- **Money mechanics** — value-based pricing, the Sequence Flip (future state → value → price → scope), pricing formulas and option tiers, objection scripts and scope creep, qualifying buyers and gatekeepers, contract terms (deposits, kill fee, termination pay), when to walk: [references/pricing-creative-work.md](references/pricing-creative-work.md). Second-hop members under `pricing-creative-work/`: value-conversation (discovery, diagnosing value), pricing-mechanics (formulas, options, retainers), objection-scripts (verbatim pushback lines, scope creep), qualifying-and-mindset (buyers, gatekeepers), engagement-terms (deposits, kill fee, termination pay), sources.

Where the topics meet: pricing and contracting the work → money mechanics; delivering the engagement once won → engagement mechanics.

**Boundary splits to respect:**
- **Devtool/product pricing and GTM → `devtools`** — this skill prices *services*; pricing a product sold to developers (landing pages, conversion, PMF metrics) lives there.
- **Indie-product economics and audience → `building-in-public`** — what to charge for your own product and company-of-one economics live there; what to charge a client lives here.
- **Session craft for presenting → `design-prototyping`** — how to build and present the work (decks, prototypes, session mechanics) lives there; the client relationship around the session (who's in the room, feedback rules, sign-off) lives here.
