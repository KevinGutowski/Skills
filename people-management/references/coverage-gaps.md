# Coverage Gaps

Use this file for people-management guidance that needs legal, HR, or organization-specific review before becoming reusable.

## Candidate gaps

- **Legal/HR boundaries:** Hiring, firing, performance management, accommodations, compensation, discrimination, and leave policies need current HR/legal process checks.
- **Remote/hybrid norms:** Meeting, comms, and performance expectations have changed quickly; promote org rules only when the user's org context is known.
- **Manager training artifacts:** Add 1:1 templates, user guides, feedback scripts, or career packets only when accepted examples are available.
- **AI management tools:** Do not promote AI-generated review, feedback, or hiring guidance without privacy, bias, and policy checks. *Partially resolved 2026-08:* the 37signals playbook is an accepted company artifact sanctioning four narrow critique-only uses (exercise pressure-testing, review-note theme finding, feedback rehearsal, level-diff analysis), folded with its own "no scripts / not a promotion bar" limits into [performance-cadence.md](performance-cadence.md). Still ungrounded and not to be promoted: pasting identifiable employee data into third-party models, AI-scored candidate ranking, and any AI role in a termination decision.
- **Single-company policy specifics:** The 37signals material carries concrete policies (a 7-work-day leave escalation threshold, a two-year level-progression requirement, a one-year retention bar, a salary floor, no manager input on pay). Treat these as one org's settings that illustrate a mechanism, never as recommended defaults; ask for the user's own policy before advising, and route leave/complaint/comp specifics through [authority-and-escalation.md](authority-and-escalation.md) with local legal verification.
- **Boundary with `design-org-influence`:** Influence up/sideways and the user's own promotion belongs there; this skill owns direct-report responsibility.
